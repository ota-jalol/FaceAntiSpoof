🎥 Stream Functionality Validation Test

Комплексная проверка работы с видеопотоками (camera stream)

1. Тест доступа к камере (getUserMedia API)

Проверяем, что браузер поддерживает WebRTC и может получить доступ к камере

2. Тест свойств видеопотока

Проверяем параметры потока: разрешение, частота кадров, статус треков

3. Тест обработки кадров

Проверяем непрерывную обработку кадров из потока через requestAnimationFrame

4. Тест детекции лиц на потоке

Проверяем работу BlazeFace детектора на реальном видеопотоке

5. Тест полного пайплайна (детекция + антиспуфинг)

Проверяем работу полного пайплайна: camera → face detection → preprocessing → anti-spoof classification

6. Тест производительности потока

Измеряем FPS, задержки, использование памяти при обработке потока

7. Тест корректного освобождения ресурсов

Проверяем, что все треки останавливаются и ресурсы освобождаются
