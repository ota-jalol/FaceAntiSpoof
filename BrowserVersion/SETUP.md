# Инструкция по запуску Browser Version

## Быстрый старт (3 шага)

### 1. Запуск HTTP-сервера

Выберите один из вариантов:

**Python 3:**
```bash
cd BrowserVersion
python -m http.server 8000
```

**Python 2:**
```bash
cd BrowserVersion
python -m SimpleHTTPServer 8000
```

**Node.js:**
```bash
npm install -g http-server
cd BrowserVersion
http-server -p 8000
```

**PHP:**
```bash
cd BrowserVersion
php -S localhost:8000
```

### 2. Откройте браузер

Перейдите по адресу: **http://localhost:8000**

### 3. Начните работу

1. Нажмите кнопку **"Start Camera"**
2. Разрешите доступ к камере
3. Дождитесь загрузки моделей (~1-2 секунды)
4. Система автоматически обнаружит ваше лицо и классифицирует его

---

## Требования

- **Браузер**: Chrome 90+, Firefox 88+, Edge 90+ (рекомендуется Chrome)
- **Камера**: Доступ к веб-камере
- **Интернет**: Для загрузки CDN библиотек (TensorFlow.js, ONNX Runtime)

## Возможные проблемы

### Камера не работает

**Проблема**: "Permission denied" или чёрный экран

**Решение**:
1. Убедитесь, что используете `http://localhost` или HTTPS
2. Проверьте разрешения браузера для камеры (иконка в адресной строке)
3. Попробуйте другой браузер

### Модели не загружаются

**Проблема**: "Failed to load model" в консоли

**Решение**:
1. Убедитесь, что файлы `.onnx` находятся в папке `models/`
2. Проверьте, что сервер запущен в корне `BrowserVersion/`
3. Откройте DevTools (F12) и проверьте вкладку Network

**Проблема**: "cannot resolve operator 'DynamicQuantizeLinear'" в консоли

**Решение**:
- Эта ошибка означает, что используется несовместимая квантизованная модель
- Убедитесь, что в `main.js` используется `best_model.onnx` (FP32), а не `best_model_quantized.onnx` (INT8)
- Проверьте, что файл `models/best_model.onnx` существует (размер ~1.9 MB)

**Проблема**: "invalid input shape" ошибка в batch-normalization

**Решение**:
- Эта ошибка означает несовместимость WebGL execution provider с BatchNormalization оператором
- Проверьте, что в `antiSpoof.js` используется только `['wasm']` execution provider (не `['webgl', 'wasm']`)
- Это уже исправлено в текущей версии кода

### Низкая производительность

**Проблема**: FPS < 10, тормозит

**Решение**:
1. ⚠️ WebGL отключен из-за несовместимости (используется WASM CPU-only)
2. Закройте другие вкладки браузера
3. Используйте Chrome (лучшая оптимизация WASM)

### CORS ошибки

**Проблема**: "CORS policy" ошибки в консоли

**Решение**:
- **НЕ** открывайте файл напрямую (file:///)
- **ОБЯЗАТЕЛЬНО** используйте HTTP-сервер (см. шаг 1)

## Тестирование

### Real Face Test (Настоящее лицо)
✅ Покажите своё лицо камере
→ Должна появиться **зелёная рамка** с надписью "REAL"

### Spoof Test (Подделка)
✅ Покажите фотографию или экран с изображением лица
→ Должна появиться **красная рамка** с надписью "SPOOF"

## Параметры настройки

### В интерфейсе:

- **Use GPU**: Ускорение через WebGL (рекомендуется включить)
- **Threshold**: Порог классификации (0.0 - 1.0)
  - Больше → меньше ложных срабатываний "REAL"
  - Меньше → меньше ложных срабатываний "SPOOF"

### В коде (main.js):

```javascript
// Изменить разрешение камеры:
const constraints = {
    video: {
        width: { ideal: 640 },  // Можно изменить на 1280
        height: { ideal: 480 }, // Можно изменить на 720
        facingMode: 'user'
    }
};

// Изменить expansion factor:
const result = await this.antiSpoof.classify(
    this.video,
    face,
    this.threshold,
    1.5  // Изменить на 1.3 или 2.0
);

// Обработка не каждого кадра (для оптимизации):
if (this.frameCount % 2 === 0) {
    // Обработка только каждого второго кадра
}
```

## Размеры файлов

```
index.html          ~4 KB
css/style.css       ~5 KB
js/preprocessing.js ~11 KB
js/antiSpoof.js     ~4 KB
js/faceDetector.js  ~3 KB
js/main.js          ~8 KB
models/best_model.onnx               1.9 MB (FP32, используется)
models/face_detection_yunet.onnx     228 KB (резерв, не используется)
```

**Общий размер**: ~2 MB + CDN библиотеки

**Примечание**: Используется FP32 модель (1.9 MB) вместо INT8 (612 KB), так как ONNX Runtime Web не поддерживает оператор `DynamicQuantizeLinear`.

---

## CDN зависимости (автоматическая загрузка)

- **TensorFlow.js**: ~6 MB (кешируется браузером)
- **BlazeFace**: ~100 KB (кешируется браузером)
- **ONNX Runtime Web**: ~7 MB (кешируется браузером)

При первом запуске загрузка может занять 5-10 секунд.
При повторных запусках всё загружается мгновенно из кеша.

## Мобильная версия

⚠️ **Не рекомендуется** для мобильных устройств из-за:
- Низкой производительности (< 10 FPS)
- Большого потребления батареи
- Ограниченной памяти

Используйте десктоп браузер для лучшего опыта.
